# thinkrail-spec-graph

Fork of [JetBrains/thinkrail](https://github.com/JetBrains/thinkrail) with an enhanced Obsidian-style Spec Graph panel.

## Status
Initial plan and SpecGraphPanel component added. Full ThinkRail source not yet mirrored (large repo).

## How to run (once full source is added)
```bash
git clone https://github.com/HarshithRL/thinkrail-spec-graph.git
cd thinkrail-spec-graph
bun install
bun run dev
```
